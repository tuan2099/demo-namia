# demo-namia

Website demo nhiều trang xây bằng HTML + Tailwind CSS (Tailwind CDN).

## Cấu trúc

```
demo-namia/
├── index.html        # Trang chủ
├── about.html        # Giới thiệu
├── services.html     # Dịch vụ
├── blog.html         # Tin tức / Blog
├── contact.html      # Liên hệ
└── assets/
    └── js/
        └── main.js   # Toggle menu mobile
```

## Chạy thử

Mở trực tiếp `index.html` bằng trình duyệt, hoặc dùng Live Server (VS Code).

## Công nghệ

- HTML5
- Tailwind CSS (CDN) — không cần build, không cần cài đặt.
